# แหล่งรวมความรู้ (Knowledge Hub & Thai PlayVerse)

แพลตฟอร์มเว็บแอปเกมการเรียนรู้และรวมการละเล่นไทย 4 ภาค (รองรับ GitHub Pages และ Progressive Web App)

## ไฟล์ทั้งหมดในโปรเจค (วางไว้ที่ Root ของ Repository ได้เลย)
- `index.html` — หน้าหลักของเว็บแอป
- `style.css` — สไตล์ชีต Responsive
- `data.js` — คลังเกมทั้ง 16 เกม และชุดคำถามความรู้
- `games.js` — ระบบตรรกะเกมทั้งหมด + ระบบบันทึกคะแนน/คำถามในเครื่อง
- `manifest.json` — ตั้งค่า PWA สำหรับติดตั้งลงหน้าจอมือถือ/แท็บเล็ต
- `sw.js` — Service Worker สำหรับโหลดเร็วและใช้งาน Offline
- `icon.svg` — ไอคอนแอปความละเอียดสูง
